# JedicliC — Plateforme SaaS Enseignants Côte d'Ivoire

Stack : **Next.js 15** (App Router, Server Actions) · **TypeScript** · **TailwindCSS** · **Supabase** (Postgres, Auth, Storage, RLS) — même architecture que le projet Menio QR Premium.

## Refonte design & éditoriale (dernier lot)

L'ensemble de l'interface et des textes a été repris avec un parti pris visuel propre au produit — l'univers de la salle de classe ivoirienne (tableau vert, papier crème, stylo rouge de correction) traduit dans un langage d'interface sobre, sans effet « généré par IA » à l'œil : pas de dégradés violets ni de halos, typographie éditoriale (Fraunces en titres, IBM Plex Sans en texte courant, IBM Plex Mono pour les chiffres/heures), composants resserrés (`Select`, `Textarea`, `Badge`, `Card`), icônes `lucide-react` contextuelles, et un jeu de couleurs `-soft`/`-strong` cohérent en clair comme en sombre.

Tous les textes ont été réécrits pour être directs, orientés vers l'action, et rassurants pour l'enseignant (ex. : « Proposition IA » plutôt que « Origine : IA », pour rappeler que tout contenu généré reste une suggestion à valider). **Aucune règle métier n'a été modifiée** : chaque page conserve exactement les mêmes actions serveur, les mêmes contrôles d'accès (rôle, statut d'abonnement, année archivée) et les mêmes requêtes Supabase qu'avant la refonte — seul l'habillage visuel et le texte ont changé.

Un logo/favicon (monogramme « J » sur fond ardoise, trait rouge signature) a été ajouté (`/icon.png`, `/apple-icon.png`, `favicon.ico`, détectés automatiquement par Next.js, plus `/public/icon-192.png` réutilisé dans les en-têtes de page).

Le projet a été vérifié avec `npm install` puis `npm run build` (Next.js 15, compilation + typecheck + génération des 40 routes) : **build réussi sans erreur**.

2. `docs/PRD_SaaS_professeur.pdf` — PRD (77 sections)

## Ce qui est livré dans ce zip (MVP fondations)

- **Base de données complète** (`supabase/migrations/0001` à `0007`) : référentiel éducatif générique multi-pays (jamais de table par pays, conformément à la Convention §9), structure multi-tenant (organisations/établissements/classes/élèves), cœur pédagogique (cours, évaluations, notes, progression, remédiation — squelette), documents, abonnements/licences, audit. **RLS activé sur toutes les tables sensibles**, avec fonctions `is_org_member` / `has_org_role` pour éviter la récursion.
- **Auth complète** : inscription, connexion, callback e-mail, middleware de protection des routes `/dashboard` et `/onboarding`.
- **Onboarding** : création du profil + de l'organisation (professeur individuel), sélection du pays.
- **Dashboard** : vue "Aujourd'hui" (cours du jour + alertes de retard de progression), Classes (CRUD), Élèves, Emploi du temps (CRUD + détection de conflit **au niveau base de données**, pas seulement l'interface), Programme & progression (comparaison officiel/réel), Évaluations (création + saisie des notes + publication), Notes (moyennes pondérées par coefficient), Analyse & remédiation (chapitres difficiles, élèves en difficulté avec traçabilité des évaluations à l'origine du signalement, création de remédiation individuelle/groupe/classe).
- **Design system** minimal (tokens CSS clairs/sombres, composants Button/Card/Input/Badge) à faire évoluer selon la direction visuelle voulue (cf. Menio : palette resserrée, typographie premium).

## Démarrage local

```bash
npm install
cp .env.example .env.local   # renseigner les clés Supabase (URL, anon key, service role)
npx supabase login
npx supabase link --project-ref <votre-ref-projet>
npx supabase db push          # applique les migrations 0001 à 0011
npm run supabase:types        # régénère src/lib/types/database.types.ts
npm run dev
```

## Déploiement

1. Créer un projet Supabase, appliquer les migrations (`supabase db push`).
2. Créer un repo GitHub, pousser ce contenu (`git init && git add . && git commit -m "Initial scaffold" && git remote add origin <url> && git push -u origin main`).
3. Connecter le repo à Vercel, renseigner les variables d'environnement (`.env.example`) dans les settings du projet.
4. Déployer.
